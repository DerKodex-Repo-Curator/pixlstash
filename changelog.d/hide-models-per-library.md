- Models can be hidden in a library, not only workflow sets: Hide model on the
  right-click menu of a model on the Model shelf, and on the menu of the Models
  rail beside it. A hidden model leaves that library's shelf and is no longer
  offered in any list that picks a model (the Run popup, Edit LoRAs, Replace
  with…, the set choosers), while every other library keeps it. No file is
  touched and a workflow that already uses the model still runs with it. Show
  › Hidden models on the shelf draws them again, where the same menu shows
  them again.
