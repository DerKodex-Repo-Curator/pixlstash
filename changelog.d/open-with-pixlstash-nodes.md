- A workflow opened in ComfyUI from PixlStash now opens with PixlStash nodes
  in it: Save Image and Save Video become the PixlStash Picture Saver and
  Video Saver, so what you queue in ComfyUI comes back into PixlStash, and a
  LoRA loader whose file is on the model shelf becomes the PixlStash Adapter
  Loader. A Load Image with a picture pinned to it (Fixed), or holding one a
  run uploaded, becomes the PixlStash Picture Loader on that picture, and,
  with ComfyUI on the same computer, a Load Checkpoint whose file is on the
  model shelf becomes the PixlStash Checkpoint Loader. A layout you arranged
  in ComfyUI is kept across these. *Open original in ComfyUI*, in the
  Workflow tab's More menu, opens the workflow with its own nodes instead.
  Needs the ComfyUI-PixlStash nodes this version ships.
