- Hiding a workflow is now each library's own choice, not the whole
  machine's. Hide the workflows a library should not show - the ones that do
  not belong in it - and they stay off the Workflows grid there while every
  other library keeps them. Set hiding works the same way: hand-made and
  from-pictures sets are hidden per library, and the set's own eye control
  hides it in the one you are in. Anything hidden before this release stays
  hidden everywhere until a library says otherwise.
